# Contributing

Thanks for your interest in the FoldNotes MCP server.

This project is **source-available for installation and use**, but it is **not run as an open
contribution project**. To keep the connector in lockstep with the FoldNotes app and CLI, it's
maintained solely by Foldsoft Pty Ltd:

- **Pull requests are not accepted.** Any opened will be closed unmerged — please don't invest
  time in one.
- **Issues are disabled** — use the channels below instead.

You are welcome to fork and modify the code for your own use under the terms of the
[MIT Licence](LICENSE).

## Where to go

- **Questions, setup help, bugs, tips, ideas** → [**Discussions**](https://github.com/Foldsoft/foldnotes-mcp/discussions).
  Community Q&A — please search first; other users may answer, and there's no guaranteed response time.
  Include your FoldNotes version, the `fn version` output, and steps to reproduce.
- **Direct support** → [support@foldnotes.io](mailto:support@foldnotes.io).
- **Security vulnerabilities** → report **privately** via GitHub's
  [Report a vulnerability](https://github.com/Foldsoft/foldnotes-mcp/security/advisories/new) button
  (the repo's **Security** tab) — not in a public thread.
