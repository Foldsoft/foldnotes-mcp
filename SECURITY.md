# Security Policy

The FoldNotes MCP server is a thin wrapper over the `fn` CLI; it stores no credentials and
opens no network ports (it speaks MCP over stdio to the client that launches it).

## Reporting a vulnerability

Please report security issues **privately**, not through a public channel:

- Email the security address published at [foldnotes.io](https://foldnotes.io).
- Include a description, affected version, and reproduction steps.

Please do not open a public issue for security reports. We'll acknowledge your report and keep
you updated on the fix.
