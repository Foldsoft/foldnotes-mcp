# Security Policy

The FoldNotes MCP server is a thin wrapper over the `fn` CLI; it stores no credentials and
opens no network ports (it speaks MCP over stdio to the client that launches it).

## Reporting a vulnerability

Please report security issues **privately**, not in Discussions or any public channel:

- Use GitHub's **[Report a vulnerability](https://github.com/Foldsoft/foldnotes-mcp/security/advisories/new)**
  button (the repo's **Security** tab) — this opens a private advisory only the maintainers can see.
- Include a description, the affected version, and reproduction steps.

We'll acknowledge your report and keep you updated on the fix.
